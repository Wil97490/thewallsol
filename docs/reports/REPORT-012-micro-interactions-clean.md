# REPORT-012 — Micro-interactions and action hierarchy

Implemented as a visual-only refinement on the public home.

- Hero and secondary actions get clearer hover/press/focus feedback.
- Podium banners and seats gain a more physical press response while selected state stays vermilion.
- Open seats receive a restrained brass edge cue without changing status semantics.
- Panel CTA receives the same light physical feedback.
- Reduced-motion disables these interaction transitions.

No business logic, data, pricing, takeover, screening, routing, dependency, or build changes.
Claude Code audit required before merge.
